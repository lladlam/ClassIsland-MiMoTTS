# Plan: Create CI 1.x Compatible MiMoTTS Plugin

## Goal
Create a ClassIsland 1.x compatible version of the MiMoTTS plugin for Issue #9 (user's Win7 whiteboard can't run CI 2.x).

## Approach: Separate Project Folder

Create `MiMoTTS.CI1/` as a separate project alongside the existing `MiMoTTS/` (CI 2.x). Avalonia → WPF conversion is too extensive for conditional compilation.

## Files to Create

```
MiMoTTS.CI1/
├── MiMoTTS.CI1.csproj          (NEW - SDK 1.7.0, net8.0-windows7.0)
├── manifest.yml                  (NEW - apiVersion: 1.7.0.0)
├── Plugin.cs                     (NEW - same structure, WPF-compatible)
├── icon.ico                      (COPY from MiMoTTS/)
├── Models/
│   └── MiMoSpeechSettings.cs    (COPY - no changes needed)
├── Shared/
│   └── GlobalConstants.cs        (COPY - no changes needed)
├── Services/SpeechService/
│   └── MiMoSpeechService.cs     (ADAPT - replace SoundFlow with IAudioService.PlayAudioAsync)
├── Controls/SpeechProviderSettingsControls/
│   ├── MiMoSpeechServiceSettingsControl.xaml      (NEW - WPF XAML)
│   └── MiMoSpeechServiceSettingsControl.xaml.cs   (NEW - WPF code-behind)
└── Themes/
    └── Generic.xaml              (NEW - WPF theme reference)
```

## Files to Modify

- `MiMoTTS.sln` - add MiMoTTS.CI1 project
- `.github/workflows/main.yml` - build both projects

## Key Changes

### 1. MiMoTTS.CI1.csproj
- `TargetFramework`: `net8.0-windows7.0`
- `ClassIsland.PluginSdk` version `1.7.0` (ExcludeAssets: runtime; native)
- `CommunityToolkit.Mvvm` (for ObservableRecipient)

### 2. manifest.yml
- `apiVersion: 1.7.0.0`
- Same id, name, description as CI 2.x version

### 3. MiMoSpeechService.cs (Audio Simplification)
Replace complex SoundFlow audio playback with `IAudioService.PlayAudioAsync`:
```csharp
// Before (CI 2.x - SoundFlow):
using var device = _audioService.TryInitializeDefaultPlaybackDevice();
var provider = new StreamDataProvider(_audioEngine, ...);
var player = new SoundPlayer(...);
device.MasterMixer.AddComponent(player);
player.Play();

// After (CI 1.x - IAudioService):
using var stream = File.OpenRead(playInfo.FilePath);
await _audioService.PlayAudioAsync(stream, volume, cancellationToken);
```
Remove all SoundFlow-related usings and fields (`_audioEngine`, `CurrentSoundPlayer`).

### 4. Settings Control XAML (Avalonia → WPF)
- Replace `ci:SpeechProviderControlBase` → `ci:SpeechProviderControlBase` (WPF version)
- Replace `FluentAvalonia.UI.Controls.SettingsExpanderItem` → `MaterialDesignThemes.Wpf.Card` or `GroupBox`
- Replace `controls:SettingsExpanderItem.Footer` pattern → direct child layout
- Add `BooleanToVisibilityConverter` for `IsVisible` bindings
- Use WPF `ComboBox`, `TextBox`, `CheckBox` (similar API)

### 5. Settings Control Code-Behind
- Replace `TopLevel.GetTopLevel(this)` + `StorageProvider.OpenFilePickerAsync` → `Microsoft.Win32.OpenFileDialog`
- Keep `ConfigureFileHelper` for config persistence
- Keep `INotifyPropertyChanged` implementation

### 6. Plugin.cs
- Same structure as CI 2.x version
- `services.AddSpeechProvider<MiMoSpeechService, MiMoSpeechServiceSettingsControl>()`

### 7. Solution File
Add MiMoTTS.CI1 project entry with new GUID.

### 8. Build Workflow
Add step to also build MiMoTTS.CI1 and include its output in the release.
